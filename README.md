## Overview

This project is a web-based presentation of my internship report completed at IMC in the role of a Data Analyst Intern.

Instead of submitting a traditional PDF report, I designed and deployed an interactive website to present:

<l>

  
+ Internship objectives
  
+ Business problems addressed

+ Data analysis workflow

+ Tools & technologies used

+ Key insights and results

+ Learnings and outcomes

The website is hosted using GitHub Pages.
</l>
<line>
### Purpose of the Project🎯

The main goal of this project was to:

+ Present internship work in a modern, professional format

+ Showcase data analysis skills visually

+ Demonstrate web deployment skills

+ Create a portfolio-ready project
